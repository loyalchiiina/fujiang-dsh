# 富江DSH完美破甲 · Fujiang Armor

Fujiang Armor, DSH के लिए एक लोकल प्लगइन है। इसमें प्रॉम्प्ट नियम अंतर्निहित हैं और Windows पर एक-क्लिक इंजेक्शन तथा अनइंस्टॉल उपलब्ध है। प्लगइन लोड होने पर इनपुट बॉक्स के ऊपर «富江破甲已激活» (Fujiang Armor सक्रिय) दिखाई देता है।

वर्तमान संस्करण: `0.4.4`। प्लगइन पहचान: `fujiang-armor`।

## 功能 · Features

- अंतर्निहित नियम प्लगइन के साथ ही तैनात हो जाते हैं; प्रॉम्प्ट मैन्युअली कॉपी करने की ज़रूरत नहीं।
- दो-स्तरीय प्रॉम्प्ट इंजेक्शन: Order 100 सामान्य कोर + Order 200 प्रबलित मिरर; कॉन्फ़िग विकल्प से एक ही स्तर चुना जा सकता है।
- डबल-क्लिक बैच फ़ाइलों से इंजेक्शन और अनइंस्टॉल।
- पर्यावरण की स्वतः जाँच; Node.js, npm या pnpm न होने पर स्वतः डाउनलोड और तैयार।
- इनपुट बॉक्स के ऊपर सक्रियता स्थिति और रीयल-टाइम निर्णय दिखाता है।

## 安装前准备 · Before you install

- Windows का उपयोग करें, DSH इंस्टॉल करें और कम से कम एक बार चलाएँ ताकि `%USERPROFILE%\.dsh` डायरेक्टरी बन जाए।
- पहली बार इंस्टॉल करने पर इंटरनेट आवश्यक है। यदि Node.js 22 या उससे नया और npm उपलब्ध हैं तो वही उपयोग होंगे; अन्यथा इंस्टॉलर आधिकारिक Node.js LTS डाउनलोड करता है, SHA256 जाँचता है और उपयोगकर्ता डायरेक्टरी में रखता है — एडमिन अनुमति आवश्यक नहीं।
- इंस्टॉल से पहले DSH पूरी तरह बंद करें, ताकि चल रहा प्रोग्राम पुराना प्लगइन उपयोग न करता रहे।

## 一键安装 · Install

1. रिलीज़ पेज से ZIP डाउनलोड करें, या रिपॉज़िटरी में «Code → Download ZIP» का उपयोग करें।
2. ZIP पूरी तरह अनज़िप करें और `点我一键注入.bat` वाला फ़ोल्डर खोलें।
3. DSH पूरी तरह बंद करें।
4. `点我一键注入.bat` पर डबल-क्लिक करें।
5. यदि कई DSH कॉन्फ़िग मिलें, तो इंस्टॉलर के संकेत के अनुसार लक्ष्य कॉन्फ़िग चुनें।
6. पर्यावरण डाउनलोड और इंस्टॉलेशन पूरा होने की प्रतीक्षा करें, फिर DSH पुनः आरंभ करें।
7. चैट खोलें और पुष्टि करें कि इनपुट बॉक्स के ऊपर «富江破甲已激活» दिखता है। अंतर्निहित नियमों के लिए चैट में सक्रियण शब्द «富江» लिखें।

प्लगइन `%USERPROFILE%\.dsh\plugins\fujiang-armor` में इंस्टॉल होता है। अनज़िप किया हुआ फ़ोल्डर सुरक्षित रखें; अनइंस्टॉल स्क्रिप्ट वहीं हैं।

डाउनलोड किया गया Node.js `%LOCALAPPDATA%\FujiangArmor\runtime` में रहता है और अगली बार पुनः उपयोग होता है। इंस्टॉलर केवल वर्तमान प्रक्रिया के लिए पर्यावरण सेट करता है और सिस्टम PATH नहीं बदलता।

## 一键卸载 · Uninstall

1. DSH पूरी तरह बंद करें।
2. अनज़िप किए फ़ोल्डर में `点我一键卸载.bat` पर डबल-क्लिक करें।
3. यदि कॉन्फ़िग चयन दिखे, तो पहले उपयोग किया गया लक्ष्य कॉन्फ़िग चुनें।
4. अनइंस्टॉल पूरा होने की प्रतीक्षा करें, फिर DSH पुनः आरंभ करें।

| --- | --- |
| DSH कॉन्फ़िग नहीं मिला | पहले DSH इंस्टॉल कर एक बार चलाएँ, `%USERPROFILE%\.dsh` बनने की पुष्टि करें, फिर इंस्टॉलर चलाएँ। |
| पर्यावरण डाउनलोड विफल | पुष्टि करें कि नेटवर्क `nodejs.org` और npm रजिस्ट्री तक पहुँचता है, फिर इंस्टॉलर दोबारा चलाएँ। |
| पर्यावरण सत्यापन विफल | इंस्टॉलर असत्यापित पैकेज उपयोग नहीं करता; नेटवर्क जाँचें और पुनः प्रयास करें। |
| स्क्रिप्ट, नियम या अन्य फ़ाइलें नहीं मिलीं | पैकेज पूरा अनज़िप करें और `prompts`, `scripts` जैसी उप-डायरेक्टरियाँ रखें। |
| इंस्टॉल सफल पर सक्रियता स्थिति नहीं दिखती | DSH पूरी तरह बंद कर पुनः आरंभ करें और पुष्टि करें कि वर्तमान कॉन्फ़िग चुना गया था। |
| अनइंस्टॉल के बाद भी स्थिति दिखती है | DSH पूरी तरह बंद कर पुनः आरंभ करें और पुष्टि करें कि सही कॉन्फ़िग अनइंस्टॉल हुआ। |

«富江破甲已激活» का अर्थ है कि प्लगइन लोड हो गया है। वास्तविक उत्तर चुने गए मॉडल, अन्य प्रॉम्प्ट और DSH संस्करण पर निर्भर करता है।

## DSH 无限重启 · Restart loop

dsh-purge का आधिकारिक पेज जाँचा गया: 1.1.52 में यदि लागू पैच स्टैम्प में `sha` नहीं है तो स्थिति असंरेखित मानी जाती है और स्टार्टअप पर पैच दोबारा लगाकर रीस्टार्ट माँगा जाता है; 1.1.53 से खाली स्टैम्प का सुधार आ गया। यदि आप 1.1.52 उपयोग करते हैं और बार-बार रीस्टार्ट होता है, तो 1.1.53 या उससे नया संस्करण अपडेट करें।

इस प्लगइन में DSH रीस्टार्ट करने वाला कोड नहीं है। संगतता पैच केवल इंस्टॉलेशन के दौरान लगाया जाता है; स्टार्टअप पर प्लगइन अब होस्ट या profile फ़ाइलें दोबारा नहीं लिखता।
