# 富江DSH完美破甲 · Fujiang Armor

富江破甲是一个用于 DSH 的本地插件，内置提示词规则，提供 Windows 一键注入和一键卸载。插件加载后，会在对话输入框上方显示「富江破甲已激活」。

当前版本：`0.4.4`。插件标识：`fujiang-armor`。

## 功能 · Features

- 随插件部署内置规则，无需手动复制提示词。
- 双层提示词注入：Order 100 通用内核 + Order 200 强化镜像，可用配置项切换单层。
- 双击批处理文件完成注入或卸载。
- 自动检测运行环境；缺少 Node.js、npm 或 pnpm 时自动下载并准备。
- 在对话输入框上方显示插件激活状态与实时破甲判定。

## 安装前准备 · Before you install

- 使用 Windows，安装 DSH，并至少启动过一次，使其生成 `%USERPROFILE%\.dsh` 本地配置目录。
- 首次安装需要联网。已有可用的 Node.js 22 或更新版本和 npm 时直接复用；环境缺失时安装器会从 Node.js 官方下载长期支持版，校验 SHA256 后放入当前用户目录，无需管理员权限。
- 完全退出 DSH 后再执行安装，避免正在运行的程序继续使用旧插件。

## 一键安装 · Install

1. 从发布页面下载 ZIP 安装包，或通过仓库页面的「Code → Download ZIP」下载源码。
2. 完整解压 ZIP，打开包含 `点我一键注入.bat` 的项目文件夹。
3. 完全退出 DSH。
4. 双击 `点我一键注入.bat`。
5. 如果检测到多个 DSH 配置，按安装器提示选择需要使用的目标配置。
6. 等待环境下载及插件安装完成，然后重新启动 DSH。
7. 打开对话，确认输入框上方显示「富江破甲已激活」。在聊天中输入激活词「富江」即可使用内置规则。

安装后的插件目录为 `%USERPROFILE%\.dsh\plugins\fujiang-armor`。请保留解压后的完整项目文件夹，卸载时仍需使用其中的脚本。

自动下载的 Node.js 位于 `%LOCALAPPDATA%\FujiangArmor\runtime`，下次安装会复用。安装器只为当前执行过程设置运行环境，不改系统 PATH。

## 一键卸载 · Uninstall

1. 完全退出 DSH。
2. 在完整解压的项目文件夹中，双击 `点我一键卸载.bat`。
3. 如果出现配置选择提示，选择此前安装的目标配置。
4. 等待卸载完成，然后重新启动 DSH。

## 常见问题 · FAQ

| 问题 | 处理方法 |
| --- | --- |
| 找不到 DSH 配置或目标配置 | 先安装并启动一次 DSH，确认 `%USERPROFILE%\.dsh` 已生成，再运行安装器。 |
| 自动下载运行环境失败 | 确认网络可以访问 `nodejs.org` 和 npm 软件包源，再重新运行安装器。 |
| 运行环境校验失败 | 安装器不会使用校验失败的下载包，请检查网络后重试。 |
| 找不到脚本、规则或其他文件 | 完整解压压缩包，保留 `prompts`、`scripts` 等子目录。 |
| 安装成功但没有显示激活状态 | 完全退出并重新启动 DSH，确认安装时选中了当前使用的配置。 |
| 卸载后仍显示激活状态 | 完全退出并重新启动 DSH，确认卸载的是此前安装的配置。 |

「富江破甲已激活」表示插件已加载。实际回复仍受所选模型、其他提示词及 DSH 版本影响。

## DSH 无限重启 · Restart loop

已核对 dsh-purge 官方发布页：1.1.52 在已应用补丁戳缺少 `sha` 时会把状态判为未对齐，并在启动时重打补丁、请求重启；上游从 1.1.53 起加入了空戳修复。若你使用 1.1.52 并遇到反复重启，请升级到 1.1.53 或更新版本。

本插件没有重启 DSH 的代码。兼容性补丁只在安装过程中应用；启动插件不会再重复写入宿主或 profile 文件。
